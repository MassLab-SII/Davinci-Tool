# MCPMark GitHub Skill Taxonomy

This skill set is anchored to MCPMark GitHub repository-maintenance task families, then expanded with adjacent professional GitHub workflows that use the same exposed tool/state space.

## Active Skill Families

- Issue triage and lifecycle management
- Pull request inspection, review, update, merge, and closure
- Repository source/history investigation
- Documentation, answer file, changelog, and report generation
- CI/CD and GitHub Actions workflow authoring
- Branch, release, and multi-branch history management
- Commit-history forensics and contributor attribution
- Label taxonomy, label assignment, and issue/PR organization
- Automation workflow authoring for CI, PR, deployment, and issue events
- Hotfix, conflict-resolution, and cross-reference workflows
- Documentation audit and maintenance for docs, tutorials, translation counts, answer files, and repository guides
- Changelog and release notes generation from commits, PRs, branches, and releases
- Contributor collaboration analytics across comments, PRs, issues, commits, and labels
- Configuration parameter audit across code, workflow, and model/config files
- Performance regression investigation with issue, commit, PR, and source evidence
- Deployment health monitoring for nightly checks, deployment status, and operational guardrails

## Design Rule

MCPMark GitHub episodes operate inside one imported repository at a time, but task domains correspond to repository templates rather than isolated tool sets. Skills should therefore be professional GitHub workflows, with `env_categories` limiting them to repositories where that workflow is realistic.

The pool intentionally has more skills than any single benchmark repository will use. Skill count is derived from distinct repository-maintenance workflows in the benchmark plus adjacent real GitHub operations, not from a fixed quota.
